# Indian Legal Document Analyzer

An AI-based system for analyzing Indian legal documents and helping users understand relevant legal information.

## Features

- Legal document analysis
- Indian law/IPC section search
- Keyword-based legal information retrieval
- Simple and user-friendly interface
- AI/NLP-based document processing

## Technologies Used

- Python
- NLP
- Machine Learning
- Streamlit
- Pandas
- Scikit-learn
