# 🇮🇳 Indian Legal Document Analyzer

An AI-powered application designed to analyze Indian legal documents and help users identify relevant legal information using Natural Language Processing (NLP) and Machine Learning techniques.

## 📌 Project Overview

Indian Legal Document Analyzer is a software application developed to simplify the analysis of legal documents. The system processes legal text, identifies relevant information, and helps users find applicable Indian legal sections.

The project is developed as an academic project to explore the application of Artificial Intelligence, Natural Language Processing, and Machine Learning in the legal domain.

## ✨ Features

* 📄 Legal document analysis
* 🔍 Indian legal section search
* 🧠 NLP-based text processing
* 📑 Relevant legal information retrieval
* ⚡ Fast and simple analysis
* 🖥️ User-friendly Streamlit interface
* 📚 Structured Indian legal data
* 📊 Easy-to-understand results

## 🛠️ Technologies Used

* **Streamlit**

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/Indian-Legal-Document-Analyzer.git
```

Navigate to the project directory:

```bash
cd Indian-Legal-Document-Analyzer
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Start the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your web browser.
